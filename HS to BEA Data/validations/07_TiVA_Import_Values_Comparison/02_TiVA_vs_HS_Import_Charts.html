Regional Aggregates

This tab shows the sum of all BEA-level imports for each region, with one point per region. Both regular and log scale plots are shown.

Understanding the Regional Comparison Plot

Y-axis (TiVA Import Values): These represent the TiVA table import values, which are the sums of imported commodities across all industries and final uses for 2023 as described by the BEA. These values are inclusive of both goods and services trades.

X-axis (Our Import Values): These are the import values for each region that we compute via our concordance from HS-to-BEA codes. These values are denominated in 2024 dollars and are non-inclusive of services imports, which will lead to some deviation from the 45-degree line.

Three Types of Data Points:

  • Blue dots (HS to BEA Mapped): These represent our actual estimates from our crosswalk methodology.
  • Blue X markers (USATradeOnline 2024): These are hard-coded values extracted from USA Trade Online for 2024, providing a contemporary comparison point for regions like Europe, Mexico, Canada, China, and Japan.
  • Pink circles (USATradeOnline 2023): These are hard-coded values extracted from USA Trade Online for 2023, acting as baseline comparisons for what we should be seeing in the absence of our crosswalk.

Goods Only: Assuming the data construction is correct (i.e. that the correct countries are included where they should be), then the deviations here should be the result of the inclusion of services imports. I identified the ~30 services exports (they are, functionally, the 'commodities' with non-zero import value from the TiVA Tables, but with 0 values from the HS to BEA crosswalk. When we remove these, we can similarly create a scatter plot of the goods-only TiVA tables vs the hs-to-bea crosswalk which itself should be goods-only. These are the final two scatters.

This tab shows the comparison aggregated to the BEA Summary level, where multiple underlying summary (U.Summary) codes are combined into broader economic categories. Each point represents a BEA Summary category for a specific region.

Understanding BEA Summary Level Aggregation

Aggregation Method: The underlying summary (U.Summary) level data from both TiVA and HS-to-BEA mappings is summed up to the broader BEA Summary level using the concordance in 02_BEA_hierarchy.csv. This provides a higher-level view of trade patterns across major economic sectors.

Regional Separation: Each region maintains its separate data points, allowing for cross-regional comparison at the summary sector level while preserving the regional dimension of the analysis.

Color Coding: Points are colored by region, making it easy to identify patterns within and across regions at this aggregated level.
